# Slides

The deck presented at the UC Berkeley capstone showcase.

**To add it:** drop the exported PDF in here as `BreachBenchmark.pdf`, then link it from the
main [README](../../README.md) documentation table:

```markdown
| [Slides](docs/slides/BreachBenchmark.pdf) | The capstone presentation deck. |
```

A PDF renders inline on GitHub when clicked, so no extra tooling is needed. Keep the file
under ~25 MB; if the export is larger, flatten the images on the way out
(`Preview → Export → Reduce File Size`, or `gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook`).

Everything the deck was built from is in [`docs/PRESENTATION_KIT.md`](../PRESENTATION_KIT.md)
— slide order, core-vs-backup figures, and the numbers that are safe to quote.
